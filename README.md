Vault 1177 is a payment platform that uses the Solana network for the construction industry. For more information, see this video:
https://www.loom.com/share/51d7686823e34848ac0f078bef31a1fa

This is just an MVP. A lot more work needs to be done before it can process payments for the construction industry.

The current setup has three accounts: Principal, Contractor and Subcontractor. Each account can submit a payment request to any Solana address. Phantom Wallet is used to process payments.

Currently, each account is allocated a Solana address, meaning that payments cannot be processed without enabling users to create their own accounts.
